# BOB ENGLISH — visual direction

## Reference direction
Warm premium café aesthetic based on the selected screenshot.

## Palette
| Token | Value | Use |
|---|---|---|
| Espresso | #170E09 | Main background |
| Roast | #21140D | Secondary background / navigation |
| Mocha | #2B1B12 | Cards |
| Cocoa | #382317 | Elevated cards |
| Cream | #FFF2E2 | Main text |
| Brass | #F4B86E | Primary accent and actions |
| Copper | #D98E42 | Secondary accent |
| Sage | #7AD09B | Success states |

## Interface principles
- Content respects top and bottom device safe areas.
- Persistent semi-transparent espresso bottom navigation: Home, Practice, Learn, Progress, Profile.
- Rounded tactile controls with press feedback and restrained shadows.
- Consistent Ionicons iconography.
- Warm café photography, with editable text and controls separate from imagery.
- First-person AI tutor Emma.

## Functional prototype scope
Navigation, scenario launch, chat composer, sample local replies, quick replies, vocabulary save/unsave, lesson navigation, and microphone-state preview.

## Not connected yet
Remote AI model, real microphone capture, speech recognition, text-to-speech, login, and cloud sync.
