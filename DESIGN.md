# EnglishTalk AI — visual direction

## Reference direction

The selected reference is a warm, premium café aesthetic rather than a generic language-learning dashboard.

## Palette

| Token | Value | Use |
|---|---|---|
| Espresso | `#170E09` | Main background |
| Roast | `#21140D` | Secondary background / navigation |
| Mocha | `#2B1B12` | Cards |
| Cocoa | `#382317` | Elevated cards |
| Cream | `#FFF2E2` | Main text |
| Brass | `#F4B86E` | Primary accent and actions |
| Copper | `#D98E42` | Secondary accent |
| Sage | `#7AD09B` | Success states |

## Interface principles

- Rounded, tactile controls with restrained shadows.
- Consistent line iconography; no emoji used as functional icons.
- Warm café photography, with editable text and controls kept separate from imagery.
- Short English labels and one primary action per screen.
- The AI partner speaks in first person as Emma and invites the learner to respond.
- The main bottom navigation remains stable across Home, Practice, Learn, Progress, and Profile.

## Screen map

1. Welcome
2. Home dashboard
3. AI chat

10. Progress
11. Profile

## Interaction scope in this first prototype

Navigation, buttons, scenario launch, chat composer, quick replies, local sample replies, vocabulary save/unsave, lesson navigation, and microphone-state preview are implemented. Remote model replies, actual audio recording, speech recognition, speech synthesis, login, and cloud sync are not connected yet.
